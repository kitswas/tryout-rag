# RAG System - Virtual GamePad FAQ

A simple RAG (Retrieval-Augmented Generation) system using LangChain with local models.

Loads a sitemap, crawls the pages, creates embeddings, stores them in a local vector store, and answers questions based on the retrieved context.

> [!NOTE]  
> I made this to learn RAG and LangChain. Not optimized for production use.  
> Parts of the codebase were generated by AI.

## Quick Start

**Prerequisites:** [uv package manager](https://docs.astral.sh/uv/getting-started/installation/)

**1. Install dependencies:**

```bash
uv sync --extra cpu    # For CPU
# or: uv sync --extra gpu  # For CUDA GPU
```

**2. Launch the UI:**

```bash
uv run python -m streamlit run src/streamlit_app.py
```

## Testing and Documentation

Run tests:

```bash
uv run python -m unittest discover
```

See API documentation generated by [pdoc](https://pdoc.dev/) for any package:

```bash
uv run pdoc src # -o docs to output to a folder instead of opening in a browser
```

## Code Formatting and Linting

We have [ruff](https://docs.astral.sh/ruff/) for code formatting and linting.
Install the [VSCode extension](https://marketplace.visualstudio.com/items?itemName=charliermarsh.ruff)
and enable `Format on Save` for a better experience.

To fix imports:

```bash
uv run ruff check --select I --fix # Sort imports
uv run ruff check --select F401 --fix # Remove unused imports
```

To check for linting errors:

```bash
uv run ruff check # Use --fix to fix the errors
```

To format the code:

```bash
uv run ruff format
```
